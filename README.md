### 👋 About Me

I'm a full-stack software engineer with a strong focus on system architecture, security design, and applied AI. I build scalable, multi-tenant SaaS systems from the ground up — covering authentication and authorization design (RBAC, JWT rotation, audit logging), backend architecture, and product engineering. I'm also an active open-source contributor through GSSoC. My current focus is on integrating **LLMs and RAG pipelines** into real, production-grade products rather than isolated proof-of-concepts.
